API Surface Mapper

Enter a domain and this maps the public API surface a browser can reach: hostnames that resolve, endpoints listed in a public API directory, and spec files it can read directly. It runs entirely in your browser.

▸

A browser cannot crawl a domain the way a server can. Cross-origin rules (CORS) stop it from reading responses off hosts you do not control, so anything unreadable is reported as a candidate to check yourself, not a confirmed API. Nothing here sends traffic through my servers.
