API Surface Mapper

Enter a domain and this maps the public API surface a browser can reach: hostnames that resolve, endpoints listed in a public API directory, and spec files it can read directly. It runs entirely in your browser.

Quickstart guide

▸

A browser cannot crawl a domain the way a server can. Cross-origin rules (CORS) stop it from reading responses off hosts you do not control, so anything unreadable is reported as a candidate to check yourself, not a confirmed API. The hosted version has no backend: every lookup runs from your browser and your own IP, so nothing you search is logged by this page. The DNS resolvers and the public directory it queries do see the domain. Run the optional server engine in Docker and those limits lift: it enumerates certificate transparency logs, reads responses directly, and parses the specs it finds.

Evidence sources: DNS-over-HTTPS (Google, Cloudflare) for host resolution, the APIs.guru open directory for documented specs, and direct fetches for readable spec files. With the server engine running it adds certificate transparency logs (crt.sh, Cert Spotter), full DNS including CNAME chains and wildcard detection, unrestricted response reads, OpenAPI and OpenID Connect parsing, GraphQL introspection, and CORS policy inspection. Authenticated crawling is out of scope for both.
